Agents

Every live Pi agent. A one-off is a session used once — a title, summary or suggestion request, not a chat. Kill targets a fingerprint; the server resolves the real id.

Containers

Every chat's container. stop ends the running Pi and stops the container (the chat resumes on its next message, with what was installed). recreate also removes the container, so the next message builds a clean one and the conversation continues. remove ends the chat and removes the container; its workspace stays.

Images

The environments chats run in. Build makes one from its Dockerfile (docker/Dockerfile is full; add more under docker/environments/<name>). A rebuilt image applies to a chat's container the next time it is recreated, and an image is only removed when nothing uses it.
